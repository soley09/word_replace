# word_replace 工具集 - 使用说明
======================================
版本: 1.2 (便携版)
日期: 2026-03-24
======================================

## 1. 简介
word_replace 是一款专为处理 Word 文档设计的绿色便携工具，主要功能包括：

### 1.1 Word 校对
- 自动识别并校正文档中的错别字。
- 支持基于自定义知识库的精准替换。
- 在原文件同目录下生成“_校准”后缀的新文件，确保原件安全。

### 1.2 知识库管理 (核心功能)
- **维护知识库入口**：点击主界面的红色按钮进入。
- **术语管理**：添加专业术语，系统可自动生成候选错词。
- **词库维护**：手动录入或批量导入“错误词=正确词”的对应关系。

### 1.3 辅助精简功能 (Document Cleaning)
- 自动合并同一发言人连续说的多段话。
- 特别适用于整理心理咨询、会议访谈等带有“姓名(时间戳): 内容”格式的记录。

---

## 2. 快速入门 (双击即用)

### 2.1 启动程序
- **唯一入口**：双击根目录下的 **`Word校对工具.exe`**。
- **无需安装**：本软件自带运行环境，无需在电脑上安装 Python 或其他插件。

### 2.2 Word 校对步骤
1. 点击 **📂 选择待校准文件**，选择您的 .docx 文档。
2. 点击 **🚀 执行校准替换**。
3. 程序处理完成后，会弹出提示并告知新文件路径。

### 2.3 知识库维护
1. 点击主界面显眼的红色按钮 **维护知识库入口**。
2. 在弹出窗口中，您可以添加新的专业术语，或在“待审核”中勾选系统生成的错词进行导入。

---

## 3. 注意事项

### 3.1 环境要求
- 仅限 **Windows** 系统。
- 请确保 **`runtime`** 文件夹与 `.exe` 文件在同一个目录下，切勿将其移动或删除。

### 3.2 格式要求 (精简功能)
- 精简功能依赖特定的文本格式识别，例如：
  `阿标(00:00:06): 您的内容...`
  `阿标(00:00:07): 您的内容...`
- 系统会自动将上述内容合并为一段。
